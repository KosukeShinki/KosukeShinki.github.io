GAME DEVELOPMENT

2Dアクションゲーム

すべてドット絵で構成された2Dアクションゲームです．ドット絵も趣味なため，自分の描いたキャラやモンスターを動かしてみたいという動機で制作を開始しました．

ゲーム説明

プレイヤーはキーボードのA/Dキーで左右に移動，Spaceキーでジャンプを行えます． また，ステージを進むうちにスキルが手に入るため，これを使って自分を強化しつつ敵を倒して進んでいくというゲームです． ゲームを開始すると会話形式でチュートリアルが始まりため，プレイヤーはすぐにやることを理解をできます． 実際に周囲の人に遊んでもらった際も最初に詰まることなく進める良いチュートリアルができた自信があります． また，セーブ機能もありシーン遷移，ボス戦後には自動でセーブが入ります．

技術的な工夫・難しかった点

タイトルから入ってすぐのような会話シーンはたくさんのセリフを各キャラクターごとに設定する必要があるため，デバッグしやすくする必要があった． これをScriptableObjectとこれを読みだすクラスを合わせて構築することでセリフの簡単な作成・修正を可能にした． また，プレイヤーや敵のアクションとシーン状態ごとの状態遷移が複雑になる問題をUniRxを用いたObserverパターンで解決した． さらに，ダメージを受けた際のわかりやすい効果が欲しかったがUnityに標準でなかったため，ダメージ時に色収差があるエフェクトをかけるシェーダーを新たに作成した．

WEB APPLICATION

3Dローグライク
カードゲーム

私が「Slay the Spire」にはまり，ドローをなくしてパズル的な要素を強くしたローグライク型カードゲーム＆パズルゲームがあったら面白いと考えて制作を開始しました． 同じく「Slay the Spire」が好きな音楽担当の友人と共同制作しています．また，3Dゲームを制作してみたかったという動機から3DCGで制作しました． オブジェクト，敵などの3Dモデルは私がBlenderでモデリングを行っています．

ゲーム説明

プレイヤーは最初に使用するデッキ(ゲーム中ではパック)と自分の体力であるゴーレムを選択します． パックとゴーレムは戦闘終了時にも報酬として手に入り，パックは4つまで，ゴーレムは3つまで所持可能です． ローグライクであり，マップはゲーム開始時に自動でランダムに生成されます． パックとゴーレムを自分にあうように集めながらボスを倒し進んでいくゲームになっています． 周囲の人からは他ゲームにない独特なゲーム性とバランスのよさが面白いと感想をいただきました．

技術的な工夫・難しかった点

このゲームを制作する際にプログラムにおいて課題となった点は大きく2つあります．

1つ目は，カードゲームのような処理に順番がありつつ途中に処理が挿入されることを考慮したデータ構造の構築です． 「Shadowverse」のようなカードゲームでは一つのカードの処理演出中に他のカードを使用した場合に，前のカードの処理が終わってから次のカードの処理が始まります．
加えて，対象に例えば「被ダメージ時に処理Aを行う」のような効果があればその処理を挿入する必要があります．
これらの課題を，関数型のキューとして定義することによって解決しました．キューは処理が終了した関数から順に削除し，未実行の処理はキュー内で演出終了を待機するようになっています．

2つ目は，ゲーム中における説明テキストの動的な変更です．
例えば，ゲーム中に「アイテムの攻撃力を+1する」のような処理が行われた場合，上がった攻撃力を説明テキストに反映する必要がありました． これを説明テキストでは{変数名}のように記述しておいて，表示側では正規表現とC#のReflectionを用いて変数の値を取得することによって解決しました．
