大学院での研究

大学院では近年SIGGRAPHでも扱われることが多いMaterial Point Method(以下，MPM)という手法を使用した調理シミュレーション手法の開発を行っています．

制作・研究期間
2024年3月〜
使用技術
C++ / CUDA / OpenGL
研究実績
情報メディア創成学類長表彰 VisualComputing2026ショート発表

技術的な工夫・難しかった点

私の研究室にMPMのテンプレートが存在しなかったため全て私がコーディングしたコードになっています．
C++，CUDAを用いてGPUも利用した実装を行い，出力したメッシュをBlenderで読み込んでレンダリングしています．
開発中にはOpenGLを用いてデバッグ用のレンダリングを行っています
実績として，CG分野で国内最大のシンポジウムであるVisualComputingで発表を行いました．
